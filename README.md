# Привет, я Серго

[English](README.en.md)

Когда обсуждаю автоматизацию, прошу показать, как вы решаете задачу сейчас. Если речь об отчёте, смотрим на исходные материалы и на документ, который вы отправили коллеге.

На одних и тех же данных сравниваю небольшую модель с более крупной. Сверяю ответы с источниками и считаю, во сколько обойдётся один отчёт в каждом случае. Если документы должны остаться у вас, подбираю открытую модель, которую можно запустить локально.

[Обсудить проект в Telegram · @lebedovichh](https://t.me/lebedovichh)

## Проекты

**Investment Digest Bot — дайджест для Telegram**  
Бот ищет материалы об инвестиционных идеях и собирает их в PDF. Выпуск можно прочитать до отправки. [Демовыпуск на вымышленных данных (7 страниц)](https://github.com/metalebedenko/investment-digest-bot/blob/main/docs/demo-digest.pdf) · [Как устроена доставка в Telegram](https://github.com/metalebedenko/investment-digest-bot/blob/main/README.ru.md#почему-подготовка-pdf-отделена-от-отправки)

**3D Landings — три демосайта для заказа деталей**  
Сделал отдельные страницы для замены сломанной детали, пробной партии и прототипа. На одной из них можно загрузить 3D-модель в формате STL и получить предварительный расчёт прямо в браузере. [Скриншот главной страницы](https://github.com/metalebedenko/3d-landings-showcase/blob/main/docs/preview.png) · [Запустить демо локально](https://github.com/metalebedenko/3d-landings-showcase)

**EarPods AI Keys — диктовка на Mac с пульта наушников**  
Центральная кнопка USB-C EarPods включает диктовку macOS, «−» удаляет символ, а «+» работает как Enter. Эту раскладку проверили на двух Mac. [Настройки кнопок](https://github.com/metalebedenko/earpods-ai-keys/blob/main/docs/media/button-settings.png) · [Что происходит после переподключения наушников](https://github.com/metalebedenko/earpods-ai-keys/blob/main/README.ru.md#диктовка-без-клавиатуры) · [Скачать для Apple silicon (предварительная версия)](https://github.com/metalebedenko/earpods-ai-keys/releases/tag/v0.1.0-preview.3)

**Кафе и рестораны Москвы — цены по округам**  
Сравнил цены по округам на выборке из 8 402 записей за лето 2022 года. В центре было дороже, чем на окраинах. Доля сетевых заведений составила около 38%. [Основные выводы](https://github.com/metalebedenko/eda-horeca-moscow#ключевые-результаты) · [Графики и расчёты](https://github.com/metalebedenko/eda-horeca-moscow/blob/main/EDA_HoReCa_Moscow.ipynb)

**mri-review — помощник для расшифровки МРТ**  
ИИ-агент объясняет заключение простыми словами и помогает подготовить вопросы для рентгенолога. При разборе снимков он может указать серию и кадр, к которым относится наблюдение. Это исследовательский прототип. [Посмотреть пример объяснения](https://github.com/metalebedenko/mri-review#как-выглядит-объяснение)

**micromanager — доступ ИИ-агента к компьютеру**  
Вы выбираете, какие файлы доступны агенту. Его запрос на правку или запуск команды можно одобрить или отклонить в терминале. Есть сборки для macOS, Windows и Linux. [Как устроено подтверждение](https://github.com/metalebedenko/micromanager#безопасность) · [Скачать v0.0.4](https://github.com/metalebedenko/micromanager/releases/tag/v0.0.4)

**Hero Limit — мод для Heroes III: Horn of the Abyss**  
В одиночной партии у человека и компьютера по одному герою на старте. По умолчанию каждый может нанять в таверне ещё двух за всю игру. Если герой погибнет в бою, запас наймов не пополнится. [Что проверено в игре](https://github.com/metalebedenko/hota-hero-limit#игровая-проверка) · [Тестовый выпуск v0.1.0 для HotA 1.8.1](https://github.com/metalebedenko/hota-hero-limit/releases/tag/v0.1.0)
