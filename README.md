# Sergo Lebedovich

I prototype AI systems and practical software tools: agent execution, local speech pipelines, desktop utilities and data workflows. I use AI-assisted development and focus on explicit interfaces, reproducible checks and documented limits.

## Selected engineering projects

| Project | What it explores | Status |
|---|---|---|
| [EarPods AI Keys](https://github.com/metalebedenko/earpods-ai-keys) | A native Swift menu-bar app that turns the USB-C EarPods remote into configurable macOS input controls. | Downloadable preview; hardware verification documented in the repository. |
| [micromanager](https://github.com/metalebedenko/micromanager) | A Rust MCP execution server with owner approvals, scoped file access, a terminal UI and peer-to-peer connections. | Experimental; binaries and architecture notes available. |
| [EasySW](https://github.com/metalebedenko/easySW) | A small native Win32/C++ tray utility that corrects English/Russian keyboard layout in selected text. | Windows executable and source build available. |
| [Radio Bububu for Android](https://github.com/metalebedenko/Radio_bububu_android) | A native Android prototype for turning news sites and public Telegram posts into a listening queue, with local speech models and text preparation. | Non-commercial research archive; validation and known limits documented. |
